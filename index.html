A ideia

Um sistema que
não fica no caminho.

Lyra OS é um projeto pessoal independente de Rodrigo Brito, criado para transformar o desktop Linux em um lugar mais coerente, acolhedor e confiável.

O nome vem da constelação de Lyra: um pequeno desenho no céu com uma identidade marcante. É dessa mesma ideia de clareza e proporção que nasce cada escolha do sistema.

A experiência

Familiar por natureza.
Lyra por escolha.

Um GNOME limpo, com o branding do Lyra aplicado com intenção. Menos ruído visual, mais espaço para aquilo que você quer fazer.

Interface clara e consistente

GNOME limpo, com tema, ícones e tipografia afinados para que tudo pareça parte do mesmo sistema.

Base sólida para o seu dia a dia

openSUSE Leap com snapshots do Btrfs: uma atualização que não deu certo pode ser desfeita pelo Snapper.

Liberdade para personalizar

Cores de destaque, papéis de parede e extensões do Sheliak, sem perder a coerência do conjunto.

A fundação

A estabilidade
como ponto de partida.

O Lyra OS usa o openSUSE Leap como base tecnológica. A versão do Lyra acompanha a numeração do Leap: o Lyra OS 16.1 é construído sobre o Leap 16.1.

Em um cenário dominado por bases Arch, Ubuntu e Fedora, o Leap traz uma alternativa sólida para quem quer usar o desktop com tranquilidade — sem abrir mão de performance ou liberdade.

Requisitos de sistema Antes de instalar.

Confira o perfil adequado para cada edição. Os valores mínimos permitem a instalação; os recomendados oferecem margem para atualizações, aplicativos e serviços.

Desktop · GNOME

Mínimos

  • CPU: x86_64, 2 núcleos
  • Memória: 4 GiB de RAM
  • Armazenamento: 24 GiB
  • Vídeo: tela 1024 × 768

Recomendados

  • CPU: x86_64, 4 núcleos
  • Memória: 8 GiB de RAM
  • Armazenamento: SSD de 40 GiB ou mais
  • Vídeo: tela Full HD
Server

Mínimos

  • CPU: x86_64, 1 núcleo
  • Memória: 2 GiB de RAM
  • Armazenamento: 8 GiB
  • Rede: Ethernet com DHCP

Recomendados

  • CPU: x86_64, 2 ou mais núcleos
  • Memória: 4 GiB de RAM ou mais
  • Armazenamento: SSD de 20 GiB ou mais
  • Rede: Ethernet Gigabit

Para o Desktop: firmware UEFI, mídia USB para instalação e conexão com a internet para atualizações. Secure Boot é suportado. A instalação usa o disco inteiro; no Server 16.1, o instalador ainda não oferece RAID nem LVM.

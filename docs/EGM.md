# Documentation output and sources (`docs`)

## Overview
User documentation published at `https://lyraos.com.br/docs/`. Authoring
sources live in `docs/content/` (Portuguese origin, plus `en/`, `es/`, `it/`);
the HTML pages in `docs/`, `docs/en/`, `docs/es/`, `docs/it/` and each
`search-index.js` are generated by `scripts/build-docs.py` and committed.
Maintenance rules are in `docs/README.md`.

## Interface
- `content/catalog.json` (per locale): article `slug`, `title`, `description`, `group`, `kind`, `scope`, `reviewed` (translations: `source_reviewed`).
- `content/locales.json`: locales with `code`, `dir`, `short`, `name`, `og_locale`, `site_lang`, `months` and UI `strings`.
- `content/<slug>.html`: article fragments (no `h1`; `h2` elements with stable ids).
- Generated `search-index.js`: defines `window.LyraDocsIndex` (title, description, url, text), consumed by `js/docs.js`.

## Invariants
- Never edit generated pages or `search-index.js` by hand; edit `content/` or `scripts/docs-template.html` and rebuild.
- Do not remove published URLs or `h2` ids without preserving access.
- Translations keep file names, `h2` ids and commands, and set `source_reviewed` to the original's `reviewed` date.

## Side Effects
- None at runtime (static files).

## Verification
- Run: `python3 scripts/build-docs.py && python3 scripts/check-docs.py && git diff --exit-code -- docs sitemap.xml` (from the repository root)

    Un'edizione per l'amministrazione dei servizi

    Lyra OS Server è un'edizione senza ambiente grafico. L'amministrazione usa la console, Vega CLI e Vega Web. La candidata 1.1 Beta 1.1 usa la base openSUSE Leap 16.1 e mantiene l'ambito funzionale della Beta 1.

    Archiviazione nella serie Server 1.1: installazione UEFI sull'intero disco, con GPT, partizione EFI e root ext4. RAID, LVM, Btrfs, Snapper, BIOS legacy e installazione non presidiata sono esclusi dal flusso documentato di questa candidata.

    Installare Server

    1. Verifica i requisiti, prepara un disco dedicato ed esegui un backup. Il contenuto del disco scelto verrà cancellato.
    2. Scarica l'immagine Server dalla sezione download e verifica i file di integrità della stessa pubblicazione.
    3. Scrivi la ISO e avvia in UEFI. L'installer è interattivo e funziona in console.
    4. Indica lingua, tastiera, fuso orario, nome della macchina e i dati dell'account richiesti.
    5. Rivedi il disco scelto e conferma l'installazione solo dopo aver controllato il riepilogo.
    6. Al termine, riavvia dal disco installato e accedi con l'account creato.

    Prepara Ethernet con DHCP per la configurazione iniziale. Le modifiche di rete, come un indirizzo statico, si effettuano dopo l'installazione.

    Amministra con Vega CLI

    In una console interattiva locale o in una sessione SSH già configurata, esegui come tuo utente:

    vega

    Usa i menu per consultare lo stato del sistema e amministrare le funzioni disponibili. L'autenticazione viene richiesta per ogni operazione privilegiata.

    Verifica il primo avvio

    Questi comandi consultano lo stato del sistema senza modificare la configurazione:

    cat /etc/os-release
ip -brief address
systemctl --failed

    Verifica la versione installata, l'indirizzo ricevuto dall'interfaccia di rete ed eventuali servizi non riusciti. La politica iniziale descritta dal progetto consente SSH e Vega Web sulla porta 9090/tcp; conferma lo stato effettivo del firewall e dei servizi nella tua installazione prima dell'accesso remoto.

    Vega Web è pensato per l'amministrazione nella rete locale. Consulta la sua documentazione per configurare l'accesso HTTPS e l'autenticazione: guida di Vega Web.

    Mantieni una copia di ripristino

    Pianifica i backup dei dati e delle configurazioni dei servizi. Questa edizione non offre il rollback con Snapper né il downgrade automatico di un'installazione sulla nuova base. Consulta aggiornamenti e risoluzione dei problemi.

    Riferimenti: note di Server Beta 1.1 e architettura di Server (in portoghese).

    Risoluzione dei problemi

    Indaga sui problemi di avvio, rete e aggiornamento e prepara una segnalazione utile per il progetto.

    Il supporto non si avvia

    1. Verifica il checksum della ISO come indicato nella guida di installazione.
    2. Conferma che l'immagine sia stata scritta sulla chiavetta USB e che il firmware stia avviando dalla voce UEFI corretta.
    3. In una VM, controlla UEFI, la memoria e il collegamento della ISO all'unità ottica.
    4. Annota il messaggio visualizzato, il modello della macchina e lo stato di Secure Boot.

    Nessuna connessione di rete

    Controlla il cavo o la connessione Wi-Fi nelle impostazioni. Su Server, conferma che la rete fornisca DHCP. Per consultare gli indirizzi delle interfacce:

    ip -brief address

    Se c'è un indirizzo ma i repository non rispondono, annota se l'errore menziona DNS, connessione o certificato. Controlla anche la data e l'ora del sistema. Queste informazioni aiutano a distinguere i problemi di rete dall'indisponibilità di un repository.

    Un aggiornamento non è riuscito

    Attendi che le altre operazioni sui pacchetti terminino e riprova. Non eliminare i file di blocco e non chiudere forzatamente il gestore. Copia il messaggio di errore e l'identificativo del repository coinvolto.

    Consulta le indicazioni sulle origini dei pacchetti prima di accettare una nuova chiave, rimuovere repository o cambiare la base.

    Raccogli informazioni sul sistema

    Per identificare la versione, il kernel e i servizi non riusciti, esegui:

    cat /etc/os-release
uname -r
systemctl --failed

    Se la tua immagine include lyra-report, eseguilo come utente normale:

    lyra-report

    Lo strumento mostra i dati raccolti per la revisione prima di creare un file locale e non esegue alcun caricamento automatico. Se il comando non è disponibile, usa le informazioni di base indicate sopra; non è necessario installare componenti di sviluppo per segnalare un problema.

    Segnala un problema riproducibile

    Apri una issue nel repository corrispondente: Desktop, Server o Vega. Cerca prima una segnalazione simile.

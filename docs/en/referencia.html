    Check the requirements

    The values below are provisional and follow the requirements published on the website. Apps and services may need more resources.

    Minimum and recommended configuration
    ResourceDesktopServer
    Minimum processorx86_64, 2 coresx86_64, 1 core
    Minimum memory4 GiB2 GiB
    Minimum disk24 GiB8 GiB
    Recommended4 cores, 8 GiB of RAM, 40 GiB SSD or larger2 or more cores, 4 GiB of RAM or more, 20 GiB SSD or larger

    Set up UEFI boot. On the Desktop, the minimum screen resolution is 1024 × 768, with Full HD recommended. On the Server, prepare an Ethernet connection with DHCP. Make sure you have internet access to get updates.

    Terms used in these guides

    ISO and live session
    An ISO is the image used to create the boot media. The live session runs the system from that media before installation.
    UEFI and Secure Boot
    UEFI is the firmware used in the documented boot flow. Secure Boot verifies the signatures of boot components according to the firmware's trust configuration.
    RPM and Zypper
    RPM is the system's package format. Zypper manages these packages and their repositories.
    Flatpak
    An app distribution format and tool with its own repositories and runtimes.
    Snapshot and backup
    A snapshot records a state of the file system. A backup is a copy of the data for recovery; an independent copy also protects against failure of the original disk.
    SHA-256 checksum
    A value used to check whether a file matches the expected content. It must be obtained from the release that corresponds to the image.

    Identify your installation

    cat /etc/os-release
uname -r

    The first command shows the system identification. The second reports the running kernel. Also include the ISO name when reporting installation problems.

    References: requirements published on the website, Desktop Alpha 7 and Server Beta 1.1 (in Portuguese).

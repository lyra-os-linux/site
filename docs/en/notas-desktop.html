    Desktop 16.1 RC 3

    What is new, limits, qualification and integrity of the GNOME Desktop candidate.

    Release notesDesktop GNOME · 16.1 RC 3Documentation review: Oct 30, 2026Translated from the Portuguese version reviewed on Oct 30, 2026

    Lyra OS Desktop 16.1 RC 3 “Odisseia” is the third and last release candidate of the GNOME Desktop on openSUSE Leap 16.1. RC 3 is the final candidate and is frozen: the same ISO is promoted by tag to the stable 16.1 release on 2026-11-19, without a rebuild.

    BaseopenSUSE Leap 16.1

    Updates from the final Leap 16.1 arrive through the update repository after installation. RC 2 remains listed as history.

    Freeze exception

    Vega gained new features after RC 2, by explicit decision of the maintainer: health diagnostics, the security review, Free up space, “My internet is not working”, boot analysis, Ask for help and the weekly check. Welcome gained the “How to ask for help” page. All of them were tested by the maintainer and passed the RC 3 gate.

    Changes since RC 2

    • Health diagnostics in Vega: on the Hardware page, Vega checks packages, disk, processor and memory under load, GPU, logs, free space and backup, security, boot time and network. Each item in attention or failure offers Fix, when there is a safe repair (with a snapshot first), or See what to do.
    • Security: the review checks the firewall, exposed ports (also under “Open ports” on the Network page), pending security fixes, SSH, encryption and accounts.
    • Free up space: on the Storage page, Vega cleans core dumps, old journal entries, the zypper cache, unused Flatpak runtimes, old kernels, snapshots, the trash, thumbnails and application caches. Folders in use by a program are left alone.
    • “My internet is not working”: on the Network page, Vega tests cable or Wi-Fi, address, router, DNS and internet, step by step and without asking for a password.
    • Ask for help: from the report, Vega prepares the text for the forum or for an issue, without personal data. See the Ask for help guide.
    • Weekly check: runs in the background and only shows a GNOME notification when something changes. It can be turned on or off and its frequency changed in Vega's Preferences.
    • Welcome 0.5.0: the “How to ask for help” page, after the network step, and the weekly check card on the Vega page.
    • Live session: the live account authorizes Vega's administrative actions without the password prompt it had no way to answer (#211), the known issue of RC 2.
    • Applications: Beam, Sulafat and Lyra Downloads no longer crash on close, with the same fix Vega already had; global shortcuts get the upstream fix in xdg-desktop-portal-gnome (#125); the image includes iputils (ping and tracepath).
    • Vega: firmware updates through fwupd and Flatpak installation no longer ask for a password, and signing key maintenance no longer fails on first boot.

    Scope and limits

    • New installations only.
    • Parental controls are basic: they do not filter websites and do not withstand a tech-savvy child.
    • GNOME is the only Desktop edition; the KDE Plasma and XFCE editions were discontinued.
    • RAID, LVM, manual partitioning and side-by-side installation remain outside the covered scenario.
    • System languages: en-US, pt-BR and es-ES, with English as the fallback.

    How the RC was qualified

    The exact ISO went through the full gate again in a QEMU/KVM virtual machine and passed every item on 2026-10-30. On UEFI with Secure Boot, the live session with and without network, the installer, first boot, Secure Boot, the sudo policy and parental controls passed; legacy BIOS, UEFI without EFI variables, snapshot rollback, languages and the OBS repository check passed as well. In the live session, the live account authorizes Vega actions without a password. Health diagnostics, “My internet is not working”, Free up space and the new Welcome pages were tested by the maintainer. The GO decision is published with the release.

    Known issues

    There are no open P0 or P1 issues. The following are accepted, with P2/P3 priority:

    • #22: with an NVIDIA card, the external monitor does not wake up after suspend or after the screen powers off. Workaround: reconnect the cable or switch virtual terminals.
    • #102: with Flatpak enabled, a supervised account can install and open Flatpak applications. Workaround: do not enable Flatpak on machines with supervised accounts.

    Risk: qualification was done in a virtual machine, and validation on physical hardware (#69) is still open.

    Integrity

    The published bundle includes the ISO, the gate evidence, the SBOMs, the checksum and the detached signature. Download the ISO, the .sha256 file and the .sha256.asc signature from the same folder and check them:

    sha256sum -c LyraOS-Desktop-16.1-rc.3-x86_64.iso.sha256
gpg --verify LyraOS-Desktop-16.1-rc.3-x86_64.iso.sha256.asc LyraOS-Desktop-16.1-rc.3-x86_64.iso.sha256

    The signature must be valid for the official release key, the same as the previous RCs, fingerprint 01B6 3EED BE6B 0791 26A0 116E FA73 53A1 31EC EFEB. The step-by-step procedure is in the installation guide.

    Stable release

    The stable 16.1 release is the RC 3 ISO itself, promoted by tag on November 19, 2026, without a rebuild. If you install RC 3, you already have the stable system and keep receiving updates as usual.

    Confira os requisitos

    Os valores abaixo são provisórios e acompanham os requisitos publicados no site. Aplicativos e serviços podem exigir mais recursos.

    Configuração mínima e recomendada
    RecursoDesktopServer
    Processador mínimox86_64, 2 núcleosx86_64, 1 núcleo
    Memória mínima4 GiB2 GiB
    Disco mínimo24 GiB8 GiB
    Recomendado4 núcleos, 8 GiB de RAM, SSD de 40 GiB ou mais2 ou mais núcleos, 4 GiB de RAM ou mais, SSD de 20 GiB ou mais

    Prepare o boot em UEFI. No Desktop, a tela mínima é 1024 × 768, com Full HD recomendado. No Server, prepare uma conexão Ethernet com DHCP. Reserve acesso à internet para obter atualizações.

    Termos usados nestes guias

    ISO e sessão live
    ISO é a imagem usada para criar a mídia de inicialização. A sessão live executa o sistema a partir dessa mídia antes da instalação.
    UEFI e Secure Boot
    UEFI é o firmware usado no fluxo de inicialização documentado. Secure Boot verifica assinaturas dos componentes de boot conforme a configuração de confiança do firmware.
    RPM e Zypper
    RPM é o formato de pacotes do sistema. Zypper gerencia esses pacotes e seus repositórios.
    Flatpak
    Formato e ferramenta de distribuição de aplicativos com repositórios e runtimes próprios.
    Snapshot e backup
    Um snapshot registra um estado do sistema de arquivos. Backup é uma cópia dos dados para recuperação; uma cópia independente protege também contra falha do disco original.
    Checksum SHA-256
    Valor usado para conferir se um arquivo corresponde ao conteúdo esperado. Deve ser obtido da publicação correspondente à imagem.

    Identifique sua instalação

    cat /etc/os-release
uname -r

    O primeiro comando apresenta a identificação do sistema. O segundo informa o kernel em execução. Inclua também o nome da ISO ao relatar problemas de instalação.

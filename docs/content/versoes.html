A versão do Lyra acompanha o openSUSE Leap

A versão segue o formato MAJOR.MINOR[.PATCH]: MAJOR.MINOR é a versão do openSUSE Leap usado como base e PATCH é uma revisão de manutenção do próprio Lyra. A linha 16.1 está em desenvolvimento.

A base openSUSE Leap determina o número do Lyra OS: o Lyra OS 16.1 é construído sobre o Leap 16.1. Até outubro de 2026 o ciclo era numerado 1.1; as imagens já publicadas com esse número continuam válidas como registro histórico.

Alpha, Beta e RC

  • Alpha: candidata de desenvolvimento para testar a integração e identificar problemas.
  • Beta: etapa de validação e estabilização, ainda anterior à versão final.
  • RC: candidata a lançamento, sujeita à aprovação dos critérios de qualidade.

Identificadores como 16.1-rc.1 distinguem as candidatas; as imagens anteriores usam 1.1-alpha.8 e 1.1-beta.1.1. Desktop e Server têm ciclos independentes. O avanço de estágio depende dos testes e da resolução de bloqueadores, não apenas de uma data.

Confira as notas da sua imagem

Consulte sempre a publicação correspondente ao arquivo que você baixou. Estes são os documentos das imagens referenciadas nesta edição dos guias:

  • Desktop 16.1 RC 2: segunda candidata de lançamento do Desktop, com controle parental básico, correção de segurança no sudo e correções do Vega; Flatpak e LinuxToys deixam de vir instalados.
  • Desktop 16.1 RC 1: primeira candidata de lançamento do Desktop sobre o Leap 16.1, com checksum assinado; congelamento estrito, apenas correções até a versão estável.
  • Desktop 1.1 Alpha 8: última Alpha do Desktop 16.1; apenas instalação nova, qualificação em máquinas virtuais e correções do instalador e da dock.
  • Desktop 1.1 Alpha 7: migração da base para Leap 16.1 e limites de instalação e upgrade.
  • Server 16.1 RC 2: segunda candidata de lançamento sobre a base RC do Leap 16.1, com as correções do Vega para administração remota.
  • Server 1.1 Beta 1.1: revisão da base preservando o escopo da Beta 1.

Suporte comunitário

O Lyra OS é um projeto independente e a versão 16.1 terá suporte comunitário. Não há prazo contratual nem data de fim de suporte prometidos sem uma política formal. O suporte da base openSUSE e o ciclo de uma versão do Lyra são informações distintas.

Para pedir ajuda, descreva a versão e a situação seguindo o guia de relato de problemas. Para detalhes da política mantida no site, consulte o documento de versionamento.

A versão do Lyra tem numeração própria

O projeto usa o formato MAJOR.MINOR.PATCH: uma geração do produto, uma evolução compatível dentro dessa geração e uma revisão de manutenção. A linha 1.1 está em desenvolvimento.

A base openSUSE Leap é identificada separadamente. Uma mudança de base não determina automaticamente o número do Lyra OS.

Alpha, Beta e RC

  • Alpha: candidata de desenvolvimento para testar a integração e identificar problemas.
  • Beta: etapa de validação e estabilização, ainda anterior à versão final.
  • RC: candidata a lançamento, sujeita à aprovação dos critérios de qualidade.

Identificadores como 1.1-alpha.7 e 1.1-beta.1.1 distinguem as candidatas. Desktop e Server têm ciclos independentes. O avanço de estágio depende dos testes e da resolução de bloqueadores, não apenas de uma data.

Suporte comunitário

O Lyra OS é um projeto independente e a versão 1.1 terá suporte comunitário. Não há prazo contratual nem data de fim de suporte prometidos sem uma política formal. O suporte da base openSUSE e o ciclo de uma versão do Lyra são informações distintas.

Para pedir ajuda, descreva a versão e a situação seguindo o guia de relato de problemas. Para detalhes da política mantida no site, consulte o documento de versionamento.

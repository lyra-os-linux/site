Antes de abrir

  • Atualize o sistema com sudo zypper up ou pelo Vega, em Software. O defeito pode já ter sido corrigido.
  • Procure nas issues do repositório por um relato parecido. Se encontrar, acrescente as suas informações num comentário em vez de abrir outro.
  • Dúvidas de uso vão para o fórum de perguntas e respostas, não para as issues.

Onde abrir

  • Desktop: instalação, boot, área de trabalho e o sistema em geral.
  • Server: a edição para servidores.
  • Defeitos de um aplicativo vão para o repositório dele, como o Vega.

Na dúvida, abra no repositório da edição que você usa. A equipe move a issue se for preciso.

O que incluir

  1. A versão do sistema, que este comando mostra:
    grep PRETTY /etc/os-release
  2. Os passos para repetir o problema.
  3. O que você esperava que acontecesse.
  4. O que aconteceu de fato, com a mensagem de erro exata.
  5. Capturas de tela ou logs, quando ajudarem. Veja como coletá-los em Reúna informações do sistema.

Com o Vega

No Desktop, o botão Pedir ajuda do diagnóstico do Vega monta um texto com as versões e o resultado dos testes, já sem dados pessoais. Cole esse texto na issue. Veja Pedir ajuda.

Falhas de segurança

Nunca relate uma vulnerabilidade numa issue pública. Use o relato privado de vulnerabilidade e leia a política de segurança.

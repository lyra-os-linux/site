Abre el centro de control

Vega reúne las tareas de administración de Lyra OS. En Desktop, busca Vega en el menú de aplicaciones y ábrelo con tu cuenta normal. La autenticación administrativa se solicita cuando una operación necesita autorización.

La Configuración de GNOME sigue disponible para las preferencias del entorno. Vega complementa esas opciones con la administración de paquetes, servicios y otros recursos del sistema.

Dónde encontrar cada tarea

  • Panel: resumen del estado del sistema y accesos directos.
  • Software: paquetes, aplicaciones Flatpak, repositorios y actualizaciones.
  • Hardware y sistema: inventario de dispositivos, kernel, almacenamiento, fecha y hora.
  • Red: conexiones, Wi-Fi, Bluetooth, cortafuegos, VPN y proxy, según los componentes disponibles.
  • Administración: usuarios, servicios, registros y procesos.
  • Copia de seguridad: funciones que dependen de las herramientas y de la configuración de almacenamiento instaladas.

Los nombres y la disponibilidad de las pantallas pueden variar según la versión instalada. Las funciones opcionales pueden aparecer como no disponibles cuando falta una dependencia.

Antes de confirmar una operación

Lee el resumen de la acción y comprueba qué se instalará, eliminará o cambiará. Espera a que termine la operación antes de iniciar otra tarea de gestión de paquetes. Si ocurre un error, anota el mensaje completo y la acción elegida.

Para gestionar programas y mantener el sistema al día, sigue Aplicaciones y actualizaciones.

Vega en la terminal

En Server con Vega CLI instalado, abre una terminal interactiva con tu cuenta y ejecuta:

vega

La interfaz de terminal comparte el servicio de administración con las demás interfaces de Vega. Las consultas no exigen ejecutar toda la aplicación como root; las acciones privilegiadas solicitan autenticación. Consulta también la guía de Server.

Referencias: documentación de Vega y Vega CLI.

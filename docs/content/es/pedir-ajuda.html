Antes de pedir

Muchos problemas se resuelven en el propio Vega. En Hardware → Diagnóstico de salud, ejecuta el diagnóstico Rápido: cada elemento en Atención o Fallo muestra qué hacer y, cuando hay una corrección segura, el botón Corregir. Para problemas de conexión, usa Red → Mi internet no funciona, que muestra en qué paso se detuvo la conexión.

Pedir ayuda desde Vega

  1. Ejecuta el diagnóstico en Hardware → Diagnóstico de salud y abre Ver informe.
  2. Haz clic en Pedir ayuda.
  3. En ¿Qué está pasando?, describe el problema: qué hiciste, qué esperabas y qué ocurrió.
  4. Revisa el texto que se compartirá. Puedes editarlo todo antes de enviar.
  5. Elige un destino: Abrir en el foro, Abrir una issue en GitHub o Copiar, para pegarlo donde quieras.

El navegador abre la página ya rellenada. No se publica nada hasta que confirmes en el propio sitio.

Qué se comparte

El texto lleva tu descripción, el modelo del equipo, las versiones del sistema, del kernel, de vegad y de Vega, el resultado de cada prueba y los hallazgos de atención y fallo, con los datos brutos acortados. Cabe en 6.000 caracteres.

El número de serie de los discos, las direcciones MAC, el nombre de la red Wi-Fi, el nombre del equipo y los nombres de las cuentas aparecen como [redacted]. Aun así, lee el texto antes de publicar: el foro y las issues son públicos.

Dónde pedir

  • Foro de preguntas y respuestas: dudas y problemas de uso. Alguien de la comunidad o del proyecto responde allí.
  • Issues del Escritorio: un defecto que puedes repetir. Busca antes un informe parecido.

Para la edición Server, usa las issues de Server y la información de Reúne información del sistema.

Sin Vega

Si Vega no abre, sigue Informa de un problema reproducible y pega la salida de los comandos indicados allí.

Lyra OS 1.1 está en desarrollo. Las imágenes Alpha y Beta son versiones de prueba. Empieza en una máquina virtual o en un ordenador dedicado y conserva una copia de tus archivos.

Elige tu edición

Lyra OS es un sistema basado en openSUSE Leap, con herramientas propias para organizar la experiencia de uso y administración. La versión de Lyra es independiente de la versión de su base.

  • Desktop: para ordenadores personales. Esta guía sigue la edición con GNOME y el centro de control Vega.
  • Server: para servicios e infraestructura, sin entorno gráfico. La administración usa la consola, Vega CLI y Vega Web.

Usa la sección de descargas para elegir la imagen publicada. Los ciclos de Desktop y Server son independientes; no esperes la misma etapa de desarrollo en ambas ediciones.

Revisa los requisitos

Consulta la tabla de requisitos de Desktop y Server antes de preparar la máquina. Reserva un disco dedicado, arranque UEFI y acceso a la red para las actualizaciones.

Pruébalo antes de instalar

En una máquina virtual, usa firmware UEFI y un disco virtual exclusivo. En Desktop, la sesión live permite comprobar vídeo, teclado, ratón, audio y red antes de continuar. Anota lo que no funcione para incluirlo en el informe de problemas.

El flujo de instalación documentado usa el disco completo. Para preparar el medio y revisar las precauciones con el disco, sigue Instalar Lyra OS.

Después del primer inicio de sesión

  1. Confirma el idioma, el teclado, la zona horaria y la conexión de red.
  2. Abre Vega desde el menú de aplicaciones y revisa el resumen del sistema.
  3. Consulta las actualizaciones disponibles y lee los cambios antes de confirmar.
  4. Configura una rutina de copia de seguridad de tus archivos en otro dispositivo.

Continúa con Conoce Vega o con la guía de Server.

Prepara el arranque en UEFI. En Desktop, la pantalla mínima es de 1024 × 768, con Full HD recomendado. En Server, prepara una conexión Ethernet con DHCP. Reserva acceso a internet para obtener actualizaciones.

Términos usados en estas guías

ISO y sesión live
La ISO es la imagen usada para crear el medio de arranque. La sesión live ejecuta el sistema desde ese medio antes de la instalación.
UEFI y Secure Boot
UEFI es el firmware usado en el flujo de arranque documentado. Secure Boot verifica las firmas de los componentes de arranque según la configuración de confianza del firmware.
RPM y Zypper
RPM es el formato de paquetes del sistema. Zypper gestiona esos paquetes y sus repositorios.
Flatpak
Formato y herramienta de distribución de aplicaciones con repositorios y runtimes propios.
Snapshot y copia de seguridad
Un snapshot registra un estado del sistema de archivos. Una copia de seguridad es una copia de los datos para su recuperación; una copia independiente protege también contra el fallo del disco original.
Checksum SHA-256
Valor usado para comprobar si un archivo corresponde al contenido esperado. Debe obtenerse de la publicación correspondiente a la imagen.

Identifica tu instalación

cat /etc/os-release
uname -r

El primer comando muestra la identificación del sistema. El segundo indica el kernel en ejecución. Incluye también el nombre de la ISO al informar de problemas de instalación.

Uma edição para administração de serviços

O Lyra OS Server é uma edição sem ambiente gráfico. Sua administração usa o console, o Vega CLI e o Vega Web. A candidata 1.1 Beta 1.1 usa a base openSUSE Leap 16.1 e mantém o escopo funcional da Beta 1.

Armazenamento na série Server 1.1: instalação UEFI em disco inteiro, com GPT, partição EFI e raiz ext4. RAID, LVM, Btrfs, Snapper, BIOS legado e instalação desassistida ficam fora do fluxo documentado dessa candidata.

Instalar o Server

  1. Confira os requisitos, prepare um disco exclusivo e faça backup. O conteúdo do disco escolhido será apagado.
  2. Baixe a imagem Server pela área de downloads e confira os arquivos de integridade da mesma publicação.
  3. Grave a ISO e inicialize em UEFI. O instalador é interativo e funciona em console.
  4. Informe idioma, teclado, fuso horário, nome da máquina e os dados da conta solicitados.
  5. Revise o disco escolhido e confirme a instalação somente depois de conferir o resumo.
  6. Ao concluir, reinicie pelo disco instalado e entre com a conta criada.

Prepare Ethernet com DHCP para a configuração inicial. Ajustes de rede, como endereço estático, são feitos após a instalação.

Administre com o Vega CLI

Em um console interativo local ou em uma sessão SSH já configurada, execute como seu usuário:

vega

Use os menus para consultar o estado do sistema e administrar as funções disponíveis. A autenticação é solicitada por operação privilegiada.

Confira o primeiro boot

Estes comandos consultam o estado do sistema sem alterar a configuração:

cat /etc/os-release
ip -brief address
systemctl --failed

Confira a versão instalada, o endereço recebido pela interface de rede e eventuais serviços com falha. A política inicial descrita pelo projeto libera SSH e Vega Web na porta 9090/tcp; confirme o estado efetivo do firewall e dos serviços na sua instalação antes do acesso remoto.

O Vega Web é voltado à administração na rede local. Consulte sua documentação para configurar acesso HTTPS e autenticação: guia do Vega Web.

Mantenha uma cópia de recuperação

Planeje backups dos dados e das configurações dos serviços. Esta edição não oferece rollback por Snapper nem downgrade automático de uma instalação sobre a nova base. Veja atualizações e diagnóstico de problemas.

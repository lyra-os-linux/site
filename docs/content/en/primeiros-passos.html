Lyra OS 1.1 is in development. Alpha and Beta images are test releases. Start in a virtual machine or on a dedicated computer and keep a copy of your files.

Choose your edition

Lyra OS is a system based on openSUSE Leap, with its own tools to organize the user and administration experience. The Lyra version is independent from the version of its base.

  • Desktop: for personal computers. This guide follows the GNOME edition and the Vega control center.
  • Server: for services and infrastructure, without a graphical environment. Administration uses the console, Vega CLI and Vega Web.

Use the downloads section to choose the published image. The Desktop and Server cycles are independent; do not expect the same development stage in both editions.

Check the requirements

See the Desktop and Server requirements table before preparing the machine. Set aside a dedicated disk, UEFI boot and network access for updates.

Try it before installing

In a virtual machine, use UEFI firmware and a dedicated virtual disk. On the Desktop, the live session lets you check video, keyboard, mouse, audio and network before proceeding. Write down anything that does not work so you can include it in a problem report.

The documented installation flow uses the entire disk. To prepare the media and review the disk precautions, follow Install Lyra OS.

After the first login

  1. Confirm language, keyboard, time zone and network connection.
  2. Open Vega from the applications menu and check the system summary.
  3. Look up the available updates and read the changes before confirming.
  4. Set up a backup routine for your files on another device.

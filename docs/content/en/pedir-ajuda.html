Before asking

Many problems can be solved in Vega itself. In Hardware → Health diagnostics, run the Quick diagnostics: each item in Attention or Failure shows what to do and, when there is a safe fix, the Fix button. For connection problems, use Network → My internet does not work, which shows at which step the connection stopped.

Ask for help from Vega

  1. Run the diagnostics in Hardware → Health diagnostics and open View report.
  2. Click Ask for help.
  3. In What is happening?, describe the problem: what you did, what you expected and what happened.
  4. Review the text that will be shared. You can edit everything before sending.
  5. Pick a destination: Open in the forum, Open a GitHub issue or Copy, to paste wherever you like.

The browser opens the page already filled in. Nothing is published until you confirm on the site itself.

What is shared

The text includes your description, the computer model, the versions of the system, kernel, vegad and Vega, the result of each test and the attention and failure findings, with the raw data shortened. It fits in 6,000 characters.

Disk serial numbers, MAC addresses, the Wi-Fi network name, the computer name and account names appear as [redacted]. Even so, read the text before posting: the forum and issues are public.

Where to ask

  • Questions and answers forum: questions and usage problems. Someone from the community or the project answers there.
  • Desktop issues: a defect you can reproduce. Search for a similar report first.

For the Server edition, use the Server issues and the information from Gather system information.

Without Vega

If Vega does not open, follow Report a reproducible problem and paste the output of the commands listed there.

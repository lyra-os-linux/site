Lyra OS Server 16.1 RC 2 “Delos” is the second release candidate of the Server on openSUSE Leap 16.1: a headless edition with a console installer and administration through Vega. The strict freeze continues: only fixes for bugs, crashes, security and critical performance are accepted.

What changed since RC 1

  • vegad 5.1.38: the firewall status can be queried outside the local session; the service now recognizes the Server edition and no longer uses the Desktop profile; administrators in the wheel group outside the local session confirm changes with their own password, while administrative reads of backup, kernel, snapshots and firewall are allowed. First-boot preparation also no longer waits for the network on every boot.
  • vega-cli 5.1.26: administrative actions over SSH ask for the password correctly instead of failing before the prompt.
  • vega-web 5.1.25: every administrative action asks for the user's password; kernel and boot, backup, snapshot, journal and firewall reads work without raw errors; the login screen and dashboard were redesigned, with light and dark themes following the system.

Scope and limits

No new application or feature was added to the image. The edition remains headless, with UEFI whole-disk installation (GPT, EFI partition and ext4 root), an administrative account with sudo, a locked root account, SSH, firewalld and Vega (vegad, vega-cli and vega-web). RAID, LVM, Btrfs, Snapper, legacy BIOS, unattended installation and upgrades between releases remain outside the 16.1 scope.

How the RC was qualified

The exact ISO went through the full Server gate in a virtual machine: clean build, live boot, installation, first boot, update, UEFI and Secure Boot, DHCP, SSH, firewalld and the three Vega components, explicitly including the items that failed in RC 1. Testing on physical hardware remains a declared risk. Tracking is in issue #25.

Integrity

The published bundle includes the ISO, the package inventory, the KIWI verification, CycloneDX and SPDX SBOMs, the checksum and the detached signature. Check them:

sha256sum -c LyraOS-Server-16.1-rc.2-x86_64.iso.sha256
gpg --verify LyraOS-Server-16.1-rc.2-x86_64.iso.sha256.asc LyraOS-Server-16.1-rc.2-x86_64.iso.sha256

The signature must be valid for the official release key, fingerprint 01B6 3EED BE6B 0791 26A0 116E FA73 53A1 31EC EFEB. Installation is described in Install the Server.

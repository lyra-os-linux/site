The media does not boot

  1. Check the ISO checksum as described in the installation guide.
  2. Confirm that the image was written to the USB drive and that the firmware is booting from the correct UEFI entry.
  3. In a VM, check UEFI, memory and that the ISO is attached to the optical drive.
  4. Record the message shown, the machine model and the Secure Boot state.

No network connection

Check the cable or the Wi-Fi connection in the settings. On the Server, confirm that the network provides DHCP. To look up the interface addresses:

ip -brief address

If there is an address but the repositories do not respond, note whether the error mentions DNS, connection or certificate. Also check the system date and time. This information helps distinguish network failures from an unavailable repository.

An update failed

Wait for other package operations to finish and try again. Do not delete lock files or force the package manager to quit. Copy the error message and the name of the repository involved.

Read the guidance on package sources before accepting a new key, removing repositories or changing the base.

Gather system information

To identify the version, the kernel and failed services, run:

cat /etc/os-release
uname -r
systemctl --failed

If your image includes lyra-report, run it as a regular user:

lyra-report

The tool shows the collected data for review before creating a local file and does not upload anything automatically. If the command is not available, use the basic information above; you do not need to install development components to report a failure.

Lyra's version follows openSUSE Leap

The version uses the MAJOR.MINOR[.PATCH] format: MAJOR.MINOR is the version of the openSUSE Leap base and PATCH is a maintenance revision of Lyra itself. The 16.1 line is in development.

The openSUSE Leap base determines the Lyra OS number: Lyra OS 16.1 is built on Leap 16.1. Until October 2026 the cycle was numbered 1.1; images already published under that number remain valid as a historical record.

Alpha, Beta and RC

  • Alpha: development candidate for testing integration and finding problems.
  • Beta: validation and stabilization stage, still before the final release.
  • RC: release candidate, subject to approval against the quality criteria.

Identifiers such as 16.1-rc.1 distinguish the candidates; earlier images use 1.1-alpha.8 and 1.1-beta.1.1. Desktop and Server have independent cycles. Moving to the next stage depends on testing and on resolving blockers, not just on a date.

Check the notes for your image

Always consult the release that corresponds to the file you downloaded. These are the documents for the images referenced in this edition of the guides:

  • Desktop 16.1 RC 2: second Desktop release candidate, with basic parental controls, a sudo security fix and Vega fixes; Flatpak and LinuxToys are no longer preinstalled.
  • Desktop 16.1 RC 1: first Desktop release candidate on Leap 16.1, with a signed checksum; strict freeze, fixes only until the stable release.
  • Desktop 1.1 Alpha 8: last Alpha of Desktop 16.1; new installations only, virtual-machine qualification and installer and dock fixes.
  • Desktop 1.1 Alpha 7: move of the base to Leap 16.1 and installation and upgrade limits.
  • Server 16.1 RC 2: second release candidate on the Leap 16.1 RC base, with the Vega fixes for remote administration.
  • Server 1.1 Beta 1.1: base revision preserving the scope of Beta 1.

Community support

Lyra OS is an independent project and version 16.1 will have community support. No contractual timeframe or end-of-support date is promised without a formal policy. Support for the openSUSE base and the cycle of a Lyra version are separate matters.

To ask for help, describe the version and the situation following the problem reporting guide. For details of the policy maintained on the website, see the versioning document (in Portuguese).

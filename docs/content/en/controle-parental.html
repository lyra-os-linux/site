What it is

Lyra OS parental controls are basic: they let a child use the computer in their own account, with rules set by a parent or guardian. They use the GNOME Parental Controls application and a supervised account created in Vega.

Create the supervised account

  1. Open Vega and go to Users.
  2. Click New user (or Edit on an existing account) and turn on Supervised account. A supervised account is never an administrator.
  3. Review what supervision covers and does not cover, then save.

Set the rules

On the account card, click Parental Controls. The application opens for that account and asks for the administrator password. There you can restrict web browsers, block applications, prevent application installation and choose the age rating. The same rules appear in Settings → System → Users.

What the supervised account cannot do

  • Administer the system or install software system-wide: all of that asks for an administrator password.
  • Log in on the text console or over SSH, or run commands with Alt+F2.
  • See the terminals or Vega in the menus and search.
  • Change or remove the rules set by the parent.

Limits

  • The controls do not resist a tech-savvy child: shortcuts, scripts or programs they create or download can still run.
  • Blocked browsers and applications disappear from the menus, but remain installed on the system.
  • The controls do not filter websites or keep browsing history.
  • Anyone with the administrator password, a bootable USB drive or access to the disk can undo the rules.

Flatpak

Flatpak is not installed by default. To use Flathub applications, open Vega in Software and click Enable Flatpak. With Flatpak enabled, a tech-savvy child can install Flatpak applications in their own account and open blocked Flatpak applications; Vega warns about this before enabling it. The other rules still apply.

References: GNOME help on parental controls and ADR 0019.

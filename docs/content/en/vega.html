Open the control center

Vega brings together Lyra OS administration tasks. On the Desktop, look for Vega in the applications menu and open it with your regular account. Administrative authentication is requested when an operation needs authorization.

GNOME Settings remains available for desktop preferences. Vega complements those options with management of packages, services and other system features.

Where to find each task

  • Dashboard: summary of the system's health and shortcuts.
  • Software: packages, Flatpak apps, repositories and updates.
  • Hardware and system: device inventory, kernel, storage, date and time.
  • Network: connections, Wi-Fi, Bluetooth, firewall, VPN and proxy, depending on the available components.
  • Administration: users, services, logs and processes.
  • Backup: features that depend on the installed tools and storage configuration.

Screen names and availability may vary with the installed version. Optional features may appear unavailable when a dependency is missing.

Before confirming an operation

Read the action summary and check what will be installed, removed or changed. Wait for the operation to finish before starting another package management task. If an error occurs, record the full message and the chosen action.

To manage programs and keep the system up to date, follow Apps and updates.

Vega in the terminal

On the Server with Vega CLI installed, open an interactive terminal with your account and run:

vega

The terminal interface shares the administration service with the other Vega interfaces. Queries do not require running the whole application as root; privileged actions request authentication. See also the Server guide.

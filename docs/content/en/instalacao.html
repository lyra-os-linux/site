1. Prepare the computer

Check the edition requirements, a network connection and a USB drive large enough for the ISO. A virtual machine with a dedicated disk also works for testing.

A whole-disk installation erases the data on the selected disk. Back up before you start and check the model and capacity of the target. The USB drive will also be erased when the image is written.

This guide covers the Desktop with GNOME. For the console installer and the storage limits of the other edition, see Install the Server. Do not use this procedure as instructions for dual boot or manual partitioning.

2. Download and verify the ISO

Go to the website's downloads section. Download the ISO and the matching checksum file from the same release directory on SourceForge.

On Linux, open a terminal in the folder containing both files. Example for the Desktop Alpha 7 image:

sha256sum -c LyraOS-Desktop-1.1-alpha.7-x86_64.iso.sha256

The name must match the downloaded file exactly. Continue only if the check reports OK. If there is a mismatch, download the files again. The checksum verifies integrity; according to its release notes, Alpha 7 does not have a detached GPG signature for the ISO.

3. Write the media and boot in UEFI mode

  1. Open a disk image writing tool. In GNOME Disks, select the USB drive and use the option to restore a disk image.
  2. Select the ISO and double-check the target device before confirming. Copying the ISO file into a folder on the USB drive does not replace writing the image.
  3. Wait for the write to finish, eject the media and restart the computer.
  4. Open the firmware boot menu and select the media's UEFI entry. The key varies by manufacturer.

In a virtual machine, attach the ISO as an optical drive and enable UEFI. Secure Boot is part of the flow planned by the project; record any boot failure for investigation.

4. Follow the Lyra Installer

  1. Wait for the live session and for the Lyra Installer to open.
  2. Fill in the language, keyboard, region and account options presented by the installer.
  3. Choose the disk dedicated to the installation and review the summary, especially the target and the storage changes.
  4. Confirm only after reviewing the data. Keep the computer on until the installation completes.
  5. Restart when prompted and remove the media to boot from the installed disk.

The screens may change between candidates. The videos on the download page show earlier versions and serve as a visual reference.

5. Check the installed system

Log in with the account you created, test the network and open Vega. Follow the first steps after installation. If the installer fails, write down the step and the message before restarting; see how to report the problem.

Reference: Desktop 1.1 Alpha 7 release notes (in Portuguese).

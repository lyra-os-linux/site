2026-10-28 · Lyra OS 16.1 RC 2 “Odisseia” available for testing

The second release candidate of Lyra OS Desktop 16.1, with GNOME on openSUSE Leap 16.1, is ready to download. The stable release is planned for 5 November 2026. Until then, only bug fixes go in.

Download from SourceForge · Release notes

What's new since RC 1

  • Basic parental controls. Create a supervised account on Vega's Users page and set the rules in GNOME's “Parental Controls” app: browsers, applications, installation and age rating. The supervised account cannot administer the system and does not see the terminals or Vega. These controls are basic: they do not filter websites.
  • Security. Only members of the wheel group can use sudo. Before, the installer let any account become root with its own password. RC 1 installs get the fix through updates.
  • Vega 5.3.2 with a new interface and several fixes: firewall zone, Bluetooth without an adapter, “Update all” leaving packages behind, and network names with accents.
  • Power and graphics. GNOME power profiles work (tuned-ppd), the Intel and AMD Vulkan drivers ship in the image, and the NVIDIA GPU powers down when idle on hybrid laptops.
  • Live session. The screen no longer locks during installation.
  • Leaner installation. Flatpak and LinuxToys are no longer preinstalled. To use Flatpak, enable it on Vega's Software page; Flathub comes with it.

Known issue

In the live session, installing programs through Vega asks for a password the live account does not have. Install the system first and the programs afterwards. The fix goes into the stable release.

A mídia não inicia

  1. Confira o checksum da ISO conforme o guia de instalação.
  2. Confirme que a imagem foi gravada no pendrive e que o firmware está iniciando pela entrada UEFI correta.
  3. Em uma VM, confira UEFI, memória e a conexão da ISO à unidade óptica.
  4. Registre a mensagem exibida, o modelo da máquina e o estado de Secure Boot.

Sem conexão de rede

Confira o cabo ou a conexão Wi-Fi nas configurações. No Server, confirme que a rede fornece DHCP. Para consultar os endereços das interfaces:

ip -brief address

Se houver endereço, mas os repositórios não responderem, registre se o erro menciona DNS, conexão ou certificado. Confira também a data e a hora do sistema. Essas informações ajudam a distinguir falhas de rede de indisponibilidade de um repositório.

Uma atualização falhou

Espere outras operações de pacotes terminarem e tente novamente. Não apague arquivos de bloqueio nem encerre o gerenciador à força. Copie a mensagem de erro e a identificação do repositório envolvido.

Confira as orientações sobre origens de pacotes antes de aceitar uma nova chave, remover repositórios ou trocar a base.

Reúna informações do sistema

Para identificar a versão, o kernel e serviços com falha, execute:

cat /etc/os-release
uname -r
systemctl --failed

Se sua imagem incluir lyra-report, execute como usuário comum:

lyra-report

A ferramenta apresenta os dados coletados para revisão antes de criar um arquivo local e não faz upload automático. Se o comando não estiver disponível, use as informações básicas acima; não é necessário instalar componentes de desenvolvimento para relatar uma falha.

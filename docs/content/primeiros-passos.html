Lyra OS 1.1 está em desenvolvimento. As imagens Alpha e Beta são versões de teste. Comece em uma máquina virtual ou em um computador dedicado e mantenha uma cópia dos seus arquivos.

Escolha sua edição

O Lyra OS é um sistema baseado no openSUSE Leap, com ferramentas próprias para organizar a experiência de uso e administração. A versão do Lyra é independente da versão de sua base.

  • Desktop: para computadores pessoais. Este guia acompanha a edição com GNOME e o centro de controle Vega.
  • Server: para serviços e infraestrutura, sem ambiente gráfico. A administração usa console, Vega CLI e Vega Web.

Use a área de downloads para escolher a imagem publicada. Os ciclos de Desktop e Server são independentes; não espere o mesmo estágio de desenvolvimento nas duas edições.

Confira os requisitos

Consulte a tabela de requisitos de Desktop e Server antes de preparar a máquina. Reserve um disco dedicado, boot UEFI e acesso à rede para atualizações.

Experimente antes de instalar

Em uma máquina virtual, use firmware UEFI e um disco virtual exclusivo. No Desktop, a sessão live permite conferir vídeo, teclado, mouse, áudio e rede antes de prosseguir. Anote o que não funcionar para incluir no relato de problemas.

O fluxo de instalação documentado usa o disco inteiro. Para preparar a mídia e revisar os cuidados com o disco, siga Instalar o Lyra OS.

Depois do primeiro acesso

  1. Confirme idioma, teclado, fuso horário e conexão de rede.
  2. Abra o Vega pelo menu de aplicativos e confira o resumo do sistema.
  3. Consulte as atualizações disponíveis e leia as alterações antes de confirmar.
  4. Configure uma rotina de backup dos seus arquivos em outro dispositivo.

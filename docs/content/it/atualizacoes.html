Installa applicazioni con Vega

Apri Vega e accedi all'area software. Cerca l'applicazione, verificane l'origine e rivedi l'operazione prima di confermare. Vega gestisce i pacchetti RPM tramite Zypper e le applicazioni Flatpak quando questo supporto è disponibile.

Gli RPM fanno parte del sistema di pacchetti della distribuzione. I Flatpak usano repository e runtime propri. La stessa applicazione può comparire in più di un'origine; scegli quella che intendi mantenere per evitare installazioni duplicate.

Aggiorna il sistema installato

  1. Collega il computer alla rete e all'alimentazione elettrica.
  2. Apri l'area aggiornamenti di Vega e aggiorna l'elenco disponibile.
  3. Leggi il riepilogo e conferma le modifiche desiderate.
  4. Attendi il risultato. Riavvia se lo strumento lo richiede o se un aggiornamento ha bisogno di un nuovo avvio per entrare in funzione.

Se preferisci il terminale, il flusso di aggiornamento dei pacchetti RPM è:

sudo zypper refresh
sudo zypper update

Il primo comando aggiorna i metadati dei repository; il secondo presenta gli aggiornamenti per la conferma. Non aggiornano le applicazioni Flatpak. Non eseguire contemporaneamente un'altra operazione sui pacchetti tramite Vega.

Cura le origini dei pacchetti

Mantieni i repository adeguati alla base della tua installazione. Non aggiungere repository di un'altra versione di Leap per ottenere un singolo pacchetto. Se compare una chiave sconosciuta o un cambio di origine inatteso, verifica l'annuncio del progetto prima di accettare.

Aggiornare non significa migrare di versione

Cambiare la base richiede una procedura specifica. Aggiornare i pacchetti non autorizza a migrare tra versioni di openSUSE Leap o tra candidate di Lyra. Attendi un percorso di migrazione documentato per la tua origine e destinazione.

Le note della Alpha 7 indicano che la migrazione delle installazioni esistenti dalla base Leap 16.0 alla 16.1 dipende da una validazione specifica. Non modificare gli indirizzi dei repository né usare un aggiornamento di distribuzione come scorciatoia.

Backup e ripristino

Conserva i tuoi file importanti su un altro dispositivo prima di modifiche importanti. Gli snapshot, se configurati, aiutano a ripristinare il sistema, ma non sostituiscono una copia indipendente dei dati. Server 1.1 usa ext4 e non offre il flusso di rollback con Snapper di Desktop.

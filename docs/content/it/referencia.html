I valori seguenti sono provvisori e seguono i requisiti pubblicati sul sito. Applicazioni e servizi possono richiedere più risorse.

Prepara l'avvio in UEFI. Su Desktop, lo schermo minimo è 1024 × 768, con Full HD consigliato. Su Server, prepara una connessione Ethernet con DHCP. Riserva l'accesso a internet per ottenere gli aggiornamenti.

Termini usati in queste guide

ISO e sessione live
La ISO è l'immagine usata per creare il supporto di avvio. La sessione live esegue il sistema da quel supporto prima dell'installazione.
UEFI e Secure Boot
UEFI è il firmware usato nel flusso di avvio documentato. Secure Boot verifica le firme dei componenti di avvio in base alla configurazione di attendibilità del firmware.
RPM e Zypper
RPM è il formato dei pacchetti del sistema. Zypper gestisce questi pacchetti e i relativi repository.
Flatpak
Formato e strumento di distribuzione delle applicazioni con repository e runtime propri.
Snapshot e backup
Uno snapshot registra uno stato del file system. Un backup è una copia dei dati per il ripristino; una copia indipendente protegge anche dal guasto del disco originale.
Checksum SHA-256
Valore usato per verificare se un file corrisponde al contenuto atteso. Deve essere ottenuto dalla pubblicazione corrispondente all'immagine.

Identifica la tua installazione

cat /etc/os-release
uname -r

Il primo comando mostra l'identificazione del sistema. Il secondo indica il kernel in esecuzione. Includi anche il nome della ISO quando segnali problemi di installazione.

Riferimenti: requisiti pubblicati sul sito, Desktop Alpha 7 e Server Beta 1.1 (in portoghese).

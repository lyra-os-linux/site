    La versión de Lyra tiene numeración propia

    El proyecto usa el formato MAJOR.MINOR.PATCH: una generación del producto, una evolución compatible dentro de esa generación y una revisión de mantenimiento. La línea 1.1 está en desarrollo.

    La base openSUSE Leap se identifica por separado. Un cambio de base no determina automáticamente el número de Lyra OS.

    Alpha, Beta y RC

    • Alpha: candidata de desarrollo para probar la integración e identificar problemas.
    • Beta: etapa de validación y estabilización, todavía anterior a la versión final.
    • RC: candidata a lanzamiento, sujeta a la aprobación de los criterios de calidad.

    Identificadores como 1.1-alpha.7 y 1.1-beta.1.1 distinguen las candidatas. Desktop y Server tienen ciclos independientes. El avance de etapa depende de las pruebas y de la resolución de bloqueos, no solo de una fecha.

    Soporte comunitario

    Lyra OS es un proyecto independiente y la versión 1.1 tendrá soporte comunitario. No se prometen plazos contractuales ni una fecha de fin de soporte sin una política formal. El soporte de la base openSUSE y el ciclo de una versión de Lyra son informaciones distintas.

    Para pedir ayuda, describe la versión y la situación siguiendo la guía para informar de problemas. Para conocer los detalles de la política mantenida en el sitio, consulta el documento de versionado (en portugués).

    Lyra OS Server

    Instala la edición para servidores y empieza a administrarla desde la consola con Vega CLI.

    Una edición para administrar servicios

    Lyra OS Server es una edición sin entorno gráfico. Su administración usa la consola, Vega CLI y Vega Web. La candidata 1.1 Beta 1.1 usa la base openSUSE Leap 16.1 y mantiene el alcance funcional de la Beta 1.

    Almacenamiento en la serie Server 1.1: instalación UEFI en el disco completo, con GPT, partición EFI y raíz ext4. RAID, LVM, Btrfs, Snapper, BIOS heredada e instalación desatendida quedan fuera del flujo documentado de esta candidata.

    Instalar Server

    1. Revisa los requisitos, prepara un disco exclusivo y haz una copia de seguridad. El contenido del disco elegido se borrará.
    2. Descarga la imagen Server desde la sección de descargas y verifica los archivos de integridad de la misma publicación.
    3. Graba la ISO y arranca en UEFI. El instalador es interactivo y funciona en consola.
    4. Indica el idioma, el teclado, la zona horaria, el nombre de la máquina y los datos de la cuenta solicitados.
    5. Revisa el disco elegido y confirma la instalación solo después de comprobar el resumen.
    6. Al terminar, reinicia desde el disco instalado e inicia sesión con la cuenta creada.

    Prepara Ethernet con DHCP para la configuración inicial. Los ajustes de red, como una dirección estática, se hacen después de la instalación.

    Administra con Vega CLI

    En una consola interactiva local o en una sesión SSH ya configurada, ejecuta como tu usuario:

    vega

    Usa los menús para consultar el estado del sistema y administrar las funciones disponibles. Se solicita autenticación en cada operación privilegiada.

    Revisa el primer arranque

    Estos comandos consultan el estado del sistema sin modificar la configuración:

    cat /etc/os-release
ip -brief address
systemctl --failed

    Comprueba la versión instalada, la dirección recibida por la interfaz de red y los posibles servicios con fallos. La política inicial descrita por el proyecto permite SSH y Vega Web en el puerto 9090/tcp; confirma el estado real del cortafuegos y de los servicios en tu instalación antes del acceso remoto.

    Vega Web está orientado a la administración en la red local. Consulta su documentación para configurar el acceso HTTPS y la autenticación: guía de Vega Web.

    Mantén una copia de recuperación

    Planifica copias de seguridad de los datos y de la configuración de los servicios. Esta edición no ofrece rollback con Snapper ni downgrade automático de una instalación sobre la nueva base. Consulta actualizaciones y diagnóstico de problemas.

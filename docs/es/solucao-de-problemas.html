    Solución de problemas

    Investiga fallos de arranque, red y actualizaciones y prepara un informe útil para el proyecto.

    El medio no arranca

    1. Comprueba el checksum de la ISO según la guía de instalación.
    2. Confirma que la imagen se grabó en la memoria USB y que el firmware arranca desde la entrada UEFI correcta.
    3. En una VM, revisa UEFI, la memoria y la conexión de la ISO a la unidad óptica.
    4. Anota el mensaje mostrado, el modelo de la máquina y el estado de Secure Boot.

    Sin conexión de red

    Revisa el cable o la conexión Wi-Fi en la configuración. En Server, confirma que la red proporciona DHCP. Para consultar las direcciones de las interfaces:

    ip -brief address

    Si hay dirección, pero los repositorios no responden, anota si el error menciona DNS, conexión o certificado. Comprueba también la fecha y la hora del sistema. Esta información ayuda a distinguir fallos de red de la indisponibilidad de un repositorio.

    Una actualización falló

    Espera a que terminen otras operaciones de paquetes e inténtalo de nuevo. No borres archivos de bloqueo ni cierres el gestor a la fuerza. Copia el mensaje de error y la identificación del repositorio implicado.

    Consulta las indicaciones sobre orígenes de paquetes antes de aceptar una clave nueva, eliminar repositorios o cambiar la base.

    Reúne información del sistema

    Para identificar la versión, el kernel y los servicios con fallos, ejecuta:

    cat /etc/os-release
uname -r
systemctl --failed

    Si tu imagen incluye lyra-report, ejecútalo como usuario normal:

    lyra-report

    La herramienta muestra los datos recopilados para su revisión antes de crear un archivo local y no los sube automáticamente. Si el comando no está disponible, usa la información básica anterior; no es necesario instalar componentes de desarrollo para informar de un fallo.

    Informa de un problema reproducible

    Abre una issue en el repositorio correspondiente: Desktop, Server o Vega. Busca primero un informe similar.

    Incluye la información siguiente:

    Edición y versión de Lyra OS:
Nombre de la ISO, si el fallo ocurrió en la instalación:
Modelo del ordenador o configuración de la VM:
UEFI y estado de Secure Boot:
Pasos para reproducir:
Resultado esperado:
Resultado observado y mensaje de error:

    Revisa las capturas y los registros antes de publicarlos. Elimina contraseñas, tokens, claves y datos personales, incluso cuando la herramienta aplique anonimización. Comparte solo los archivos necesarios para explicar el problema.

    Referencia: diagnóstico con lyra-report.
